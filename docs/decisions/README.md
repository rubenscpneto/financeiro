# Architecture decision records

Record non-trivial technical and workflow decisions here. Use the next available four-digit number and a descriptive filename: `NNNN-short-title.md`. Keep accepted records as history; add a new record to supersede a decision and link the related records.

Use this format:

```markdown
# NNNN — Decision title

## Context

What problem or constraints require a decision?

## Decision

What was chosen and why?

## Consequences

What benefits, costs, and follow-up work result?

## Status

Proposed / Accepted / Superseded (link the replacement when applicable)

## Date

YYYY-MM-DD
```
